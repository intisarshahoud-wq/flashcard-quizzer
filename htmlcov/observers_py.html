1"""Observer pattern plumbing for quiz session events. 

2 

3The quiz engine announces what happened; it never decides what should be done 

4about it. Printing feedback, writing a log line and updating the saved progress 

5file are three unrelated reactions to the same events, and each lives in its 

6own observer. Adding a fourth reaction -- a sound effect, a web hook, a 

7leaderboard -- means writing one class and attaching it, with no change to the 

8engine at all. 

9"""

152class ProgressObserver(BaseSessionObserver): 

153 """Feeds every answer into the :class:`~progress_store.ProgressStore`. 

154 

155 The store is written once, at the end of the session, rather than after 

156 every answer: a quiz is short, and one atomic write is both faster and less 

157 likely to leave a half-updated file behind. 

158 """ 

159

164 store: The store to update.

166 """

170 self.save_error: str | None = None

174 """Return the store this observer updates.""" 

175 return self._store
